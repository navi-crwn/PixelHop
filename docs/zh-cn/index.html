pixel.hel.ink
功能

图床该做的都做到。不该做的一样不做。

没有把好功能藏起来的付费版。每个账号都能使用全部功能。

清除位置，保留画质

手机照片带有 GPS 坐标和相机序列号。PixelHop 通过重写文件容器来删除 EXIF、XMP 和 IPTC，像素绝不会被重新压缩；横着拍的照片还会先自动摆正。

你需要的每一种链接

易读的链接，例如 beach-sunset-x7Kp2Q，以及直链、Markdown、HTML、BBCode 和二维码。在 Discord、X、WhatsApp 和论坛中预览效果都很好。

相册

一次拖入多张照片，作为一个相册链接分享。

自动删除

10 分钟、一天或一个月后自动删除。访客会得到专属的删除链接。

ShareX & API

一键生成 ShareX 配置，带密钥的 REST API。旧版 PixelHop 2 的配置仍然可用。

自行托管

单个程序、Docker 镜像或 systemd。支持本地磁盘、R2、MinIO、B2、Contabo。

内置审核

举报、隐藏/删除、IP 封禁、锁定或停用账号、警告。

一次复制所有链接

批量上传后，一键复制全部直链、页面、Markdown、BBCode 或 HTML 链接。相册也可打包下载 ZIP。

私密或密码保护

按图片设置：任何有链接的人、仅自己，或需要密码。锁定的文件无法被盗链。

按 URL 调整尺寸，查看统计

?w=800&format=webp 可生成任意尺寸。所有者可以看到每天的浏览量以及哪些网站链接了图片。

可安装应用、HEIC、水印

添加到主屏幕后，可直接把照片分享给它。iPhone 的 HEIC 照片会自动转换。可为单张或整批图片添加水印。

Webhook、oEmbed、命令行

带签名的 Webhook，WordPress 和 Notion 嵌入，Explore 动态，以及终端里的 pixelhop push。

与 HEL.ink 共用一个账号

在 p.hel.ink 上，你用 HEL.ink 账号登录：短链接、个人主页和图片使用同一个登录，支持 Google 登录和两步验证。自行托管时可以关闭此功能。

旧链接继续可用

PixelHop 2 的所有页面链接、直链和缩略图链接，以及它的 ShareX 配置和上传结果页面，都和以前完全一样。

Studio

一个从不上传你照片的照片工作室。

大多数工具借助 Canvas 和 WebAssembly 在你自己的设备上运行，只有你点击“上传结果”时图片才会离开设备。较重的 AI 工具在服务器上为会员运行，并且不保留任何内容。

  • 压缩、调整尺寸、裁剪、转换为 JPG、PNG、WebP 或 AVIF，实时显示文件大小。
  • 调整与旋转：亮度、对比度、色彩、黑白、翻转。
  • 模糊与像素化人脸、车牌和姓名，然后再分享。
  • 图片转文字（OCR），支持 30 种语言，同一张图片中可同时识别多种语言。
  • 移除背景，AI 模型直接在浏览器中运行。
  • 调色板和二维码生成器（PNG 或 SVG）。
  • 在服务器上，供会员使用：一秒去除背景、自动模糊人脸、魔法橡皮擦和 2 倍高清放大。在内存中处理，从不存储。
  • 批量处理：对多张图片执行相同步骤，然后得到一个 ZIP 或一个相册。

自行托管

一分钟即可运行。

不需要 PHP、Python、MySQL，也不需要 cron。你创建的第一个账号就是管理员。

# Linux（amd64）。arm64、macOS 和 Windows 版本请见 Releases 页面。
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

API

从任何地方上传。

在设置中创建密钥，然后用任意 HTTP 客户端发送文件。返回的是普通 JSON，包含直链、页面链接、缩略图和嵌入代码。

FAQ

常见问题

免费吗？

是的。p.hel.ink 可免费使用，代码采用 MIT 许可，所以你可以运行自己的副本，甚至用于商业用途。

需要注册账号吗？

不需要。访客也能上传，并为每张图片获得一个专属删除链接（同时保存在浏览器中）。账号额外提供图库、可查看的存储配额和 API 密钥。

工作室是私密的吗？

大多数工具在你的设备上运行，图片不会发送到任何地方。标记为“服务器”的 AI 工具（快速去背景、人脸模糊、魔法橡皮擦、高清放大）会把图片发送到你正在使用的服务器，在内存中处理后丢弃；何时使用由你决定。

可以使用哪些存储？

本地磁盘，或任意兼容 S3 的存储桶：AWS S3、Cloudflare R2、MinIO、Backblaze B2、Wasabi、Contabo。设置 S3_PUBLIC_URL 即可直接通过 CDN 提供图片。

如何举报图片？

每个图片页面都有举报按钮。举报会直接进入审核队列，审核员可以隐藏或删除图片，并封禁上传者。

为什么选择 Go？

图床的大部分时间都在搬运字节。Go 用很少的内存就能做到，能编译成一个包含一切的文件，还能交叉编译到任何服务器。PixelHop 2 需要 PHP、MySQL、Python 和 cron；PixelHop 3 只需要它自己。
