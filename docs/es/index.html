HOP · Alojamiento de imágenes y taller fotográfico

Suelta una imagen, limpia metadatos, comparte al instante

PixelHop ofrece subidas rápidas de imágenes, galerías de álbumes y un taller fotográfico privado en tu navegador. Enlaces cortos y limpios en p.hel.ink y tu panel en pixel.hel.ink. Binario único en Go, autoalojable, código abierto (MIT).

Las direcciones activas en esta página enlazan a los sitios públicos de la familia HOP.

Lo que hace PixelHop

  • Subidas rápidas y enlaces limpios

    Arrastra fotos o capturas para obtener enlaces cortos en p.hel.ink/{slug}, enlaces directos, Markdown y códigos incrustables.

  • Metadatos eliminados por defecto

    Las coordenadas GPS, números de serie y etiquetas EXIF se eliminan reescribiendo el contenedor sin recomprimir los píxeles originales.

  • Taller fotográfico privado en el navegador

    Comprime, redimensiona, recorta, convierte a WebP/AVIF, desenfoca detalles sensibles y aplica OCR directamente en tu navegador sin subir la imagen.

  • Un solo inicio de sesión: HOP ID

    Inicia sesión con tu cuenta de SSO HOP ID en todas las aplicaciones HOP, o utiliza PixelHop como invitado.

  • Álbumes y compartición masiva

    Sube varias imágenes a la vez en una galería adaptable, copia todos los enlaces en un clic o descarga un archivo ZIP completo.

  • Enlaces con caducidad y privados

    Configura temporizadores de autodestrucción (10 minutos, 24 horas, 30 días) o protege con contraseña. Los invitados obtienen tokens de eliminación privados.

  • ShareX y API REST

    Configuración directa para ShareX, subidas por CLI con pixelhop push y tokens de API personales para integraciones.

  • Binario único en Go autoalojable

    Ejecutable Go ligero de ~16 MB con SQLite integrado, compatible con disco local o almacenamiento S3.

Autoalojamiento

PixelHop es autoalojable. Compila y ejecuta el binario único en cuestión de segundos:

git clone https://github.com/navi-crwn/PixelHop.git
cd PixelHop
go build -o pixelhop ./cmd/pixelhop
./pixelhop

Requisitos

Go 1.22+ y SQLite. Consulta el README en GitHub para ver guías de inicio rápido, comandos Docker y pruebas.

Configuración de acceso

El inicio de sesión usa SSO HOP ID. Configura HOP_HUB_URL, HOP_APP=pixelhop y HOP_SSO_SECRET en tu entorno, o ejecuta en modo independiente.

Base de datos y almacenamiento

PixelHop utiliza SQLite integrado con almacenamiento en disco local por defecto. Configura variables S3 para almacenamiento en la nube.

Tanto el modo independiente como el SSO están totalmente admitidos en autoalojamiento.

Preguntas frecuentes

¿PixelHop reduce la calidad de mis imágenes?

No. La eliminación de metadatos limpia encabezados EXIF y GPS sin volver a codificar los píxeles, preservando la fidelidad visual original.

¿Necesito registrarme para subir imágenes?

No. Las subidas de invitados están totalmente permitidas con tokens de eliminación privados. Iniciar sesión con HOP ID añade galerías y claves API.

¿Puedo alojar PixelHop en mi servidor?

Sí. PixelHop se compila en un binario autónomo en Go sin dependencias externas. Consulta las instrucciones en el README del repositorio.

¿Dónde informo de errores o problemas de seguridad?

Abre una incidencia en GitHub o escribe a security@hel.ink para divulgación responsable de vulnerabilidades.
