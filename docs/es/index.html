Funciones

Todo lo que debe hacer un alojamiento de imágenes. Nada de lo que no.

Sin plan premium que esconda lo bueno. Todas las cuentas tienen todas las funciones.

Ubicación eliminada, calidad intacta

Las fotos del móvil llevan coordenadas GPS y números de serie de la cámara. PixelHop elimina EXIF, XMP e IPTC reescribiendo el contenedor del archivo, así que los píxeles nunca se vuelven a comprimir, y antes endereza las fotos giradas.

Todos los enlaces que necesitas

Enlaces legibles como beach-sunset-x7Kp2Q, un enlace directo, Markdown, HTML, BBCode y un código QR. Las vistas previas se ven bien en Discord, X, WhatsApp y foros.

Álbumes

Suelta varias fotos y compártelas con un solo enlace de galería.

Autodestrucción

Borrar a los 10 minutos, al día o al mes. Los invitados reciben un enlace privado para borrar.

ShareX & API

Configuración de ShareX en un clic, API REST con claves. Las configuraciones antiguas de PixelHop 2 siguen funcionando.

Alójalo tú mismo

Un binario, una imagen de Docker o systemd. Disco, R2, MinIO, B2, Contabo.

Moderación integrada

Denuncias, ocultar/borrar, bloqueo de IP, bloquear o suspender cuentas, avisos.

Copia todos los enlaces a la vez

Tras una subida múltiple: todos los enlaces directos, de página, Markdown, BBCode o HTML con un clic. También descarga de la galería en ZIP.

Privado o con contraseña

Por imagen: cualquiera con el enlace, solo tú, o con contraseña. Los archivos bloqueados no se pueden enlazar desde otros sitios.

Redimensionar por URL, estadísticas de visitas

?w=800&format=webp genera cualquier tamaño. Los propietarios ven las visitas por día y qué sitios los enlazan.

App instalable, HEIC, marca de agua

Añádela a tu pantalla de inicio y comparte fotos directamente con ella. Las fotos HEIC del iPhone se convierten solas. Pon marca de agua a una imagen o a un lote entero.

Webhooks, oEmbed, CLI

Webhooks firmados, inserciones para WordPress y Notion, un feed Explore y pixelhop push desde la terminal.

Una cuenta con HEL.ink

En p.hel.ink inicias sesión con tu cuenta de HEL.ink: el mismo acceso para enlaces cortos, páginas de bio e imágenes, con inicio de sesión de Google y códigos de dos factores. Si lo alojas tú, puedes desactivarlo.

Los enlaces antiguos siguen funcionando

Todos los enlaces de página, directos y de miniatura de PixelHop 2, además de sus configuraciones de ShareX y páginas de resultados de subida, responden igual que antes.

Studio

Un estudio de fotos que nunca sube tu foto.

La mayoría de las herramientas funcionan en tu propio dispositivo con Canvas y WebAssembly, así que la imagen solo sale de él si pulsas «Subir resultado». Las herramientas de IA más pesadas se ejecutan en el servidor, para miembros, y no guardan nada.

  • Comprimir, redimensionar, recortar, convertir a JPG, PNG, WebP o AVIF, con el tamaño del archivo en vivo.
  • Ajustar y girar: luz, contraste, color, blanco y negro, voltear.
  • Desenfocar y pixelar caras, matrículas y nombres antes de compartir.
  • Imagen a texto (OCR) en 30 idiomas, varios a la vez en la misma imagen.
  • Quitar el fondo con un modelo de IA que se ejecuta en el navegador.
  • Paleta de colores y un generador de códigos QR (PNG o SVG).
  • En el servidor, para miembros: quitar el fondo en un segundo, desenfoque automático de caras, una goma mágica y ampliación HD 2×. Se procesa en memoria y nunca se guarda.
  • Por lotes: aplica los mismos pasos a muchas imágenes y obtén un ZIP o un álbum.

Autoalojar

Funcionando en un minuto.

Sin PHP, sin Python, sin MySQL, sin cron. La primera cuenta que crees será la de administrador.

# Linux (amd64). Las versiones para arm64, macOS y Windows están en la página de Releases.
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

FAQ

Preguntas

¿Es gratis?

Sí. p.hel.ink es gratuito y el código tiene licencia MIT, así que puedes ejecutar tu propia copia, incluso con fines comerciales.

¿Necesito una cuenta?

No. Los invitados pueden subir imágenes y reciben un enlace privado para borrar cada una (también guardado en su navegador). Una cuenta añade una galería, una cuota de almacenamiento visible y claves de API.

¿El estudio es privado?

La mayoría de las herramientas funcionan en tu dispositivo y nunca envían la imagen a ningún sitio. Las herramientas de IA marcadas como «servidor» (quitar el fondo rápido, desenfoque de caras, goma mágica, ampliación HD) la envían al servidor que usas, la procesan en memoria y la descartan; tú decides cuándo usarlas.

¿Qué almacenamiento puedo usar?

El disco local o cualquier bucket compatible con S3: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Configura S3_PUBLIC_URL para servir las imágenes directamente desde una CDN.

¿Cómo denuncio una imagen?

Cada página de imagen tiene un botón de denuncia. Las denuncias van directamente a la cola de los moderadores, que pueden ocultar o borrar la imagen y bloquear a quien la subió.

¿Por qué Go?

Un alojamiento de imágenes pasa el tiempo moviendo bytes. Go lo hace con poca memoria, compila a un solo archivo con todo dentro y se compila para cualquier servidor. PixelHop 2 necesitaba PHP, MySQL, Python y cron; PixelHop 3 solo se necesita a sí mismo.
