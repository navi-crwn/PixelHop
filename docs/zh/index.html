HOP · 图像托管与图片工坊

拖入图片，抹除元数据，数秒内分享

PixelHop 提供极速图片上传、相册合集以及完全在浏览器内运行的私密图片工坊。在 p.hel.ink 获得简洁短链，在 pixel.hel.ink 管理后台。单一 Go 二进制文件，支持私有化部署，开源 (MIT)。

页面中的有效地址均指向 HOP 家族的公共服务。

PixelHop 功能亮点

  • 极速上传与简洁链接

    拖放照片、截屏或插画，即刻获得 p.hel.ink/{slug} 格式的友好短链、直链、Markdown 及嵌入代码。

  • 默认抹除敏感元数据

    通过重构容器抹除 GPS 坐标、设备序列号和 EXIF 标签，原始像素绝不重新压缩。

  • 浏览器内私密工坊

    在浏览器本地直接完成压缩、缩放、裁剪、转换为 WebP/AVIF、人脸打码与 OCR 文字识别，无需提前上传。

  • 全生态统一登录：HOP ID

    借助 HOP ID 单点登录畅行 HOP 全家族应用，亦支持游客直接上传。

  • 相册与批量共享

    一次上传多张图片并生成响应式图集，一键复制全部链接，或打包下载 ZIP 压缩包。

  • 阅后即焚与密码保护

    可设定自毁时限（10分钟、24小时、30天）或加设访问密码。游客享有专属删除凭证。

  • ShareX 与 REST API

    开箱即用的 ShareX 配置、pixelhop push 命令行工具以及个人 API 令牌。

  • 单一 Go 二进制私有化运行

    极轻量约 16 MB Go 可执行程序，内置 SQLite，支持本地磁盘或兼容 S3 的对象存储。

自行搭建

PixelHop 支持完全私有化部署。数秒内编译并运行单二进制文件：

git clone https://github.com/navi-crwn/PixelHop.git
cd PixelHop
go build -o pixelhop ./cmd/pixelhop
./pixelhop

运行要求

Go 1.22+ 与 SQLite。完整快速上手指引、Docker 命令及测试套件见 GitHub README。

登录配置

登录接入 HOP ID 单点登录。启动前在环境中配置 HOP_HUB_URL、HOP_APP=pixelhop 和 HOP_SSO_SECRET，亦可独立模式运行。

数据库与存储

PixelHop 默认采用内置 SQLite 数据库与本地磁盘存储。配置 S3 环境变量即可切换为云存储桶。

私有化部署全面支持独立模式与 SSO 统一登录模式。

常见问题

PixelHop 会降低或压缩我的图片画质吗？

不会。元数据剥离仅重写文件容器头部以剔除 EXIF 和 GPS，绝不对像素本身重新编码。

上传图片必须注册账号吗？

不需要。完全支持游客免登录上传并附带私密删除凭证。登录 HOP ID 可解锁相册管理与持久 API Key。

我可以部署在自己的服务器上吗？

完全可以。PixelHop 编译为单一独立二进制文件，无外部运行时依赖。参见 GitHub 仓库说明。

如何报告问题或漏洞？

欢迎在 GitHub 提交 Issue，或致信 security@hel.ink 进行负责任的安全漏洞披露。
