HOP · Hospedagem de imagens e estúdio

Solte uma imagem, limpe metadados, compartilhe em segundos

O PixelHop oferece uploads rápidos de imagens, galerias de álbuns e um estúdio fotográfico privado diretamente no seu navegador. Links curtos limpos em p.hel.ink e seu painel em pixel.hel.ink. Binário Go único, auto-hospedável, código aberto (MIT).

O que o PixelHop faz

  • Uploads rápidos e links limpos

    Arraste fotos, capturas de tela ou ilustrações para gerar links curtos em p.hel.ink/{slug}, links diretos, Markdown e códigos de incorporação.

  • Metadados removidos por padrão

    Coordenadas GPS, números de série e dados EXIF são removidos na reescrita do contêiner, sem recomprimir os pixels originais.

  • Estúdio fotográfico privado no navegador

    Comprima, redimensione, corte, converta para WebP/AVIF, desfoque detalhes sensíveis e execute OCR no navegador sem fazer upload prévio.

  • Um único login: HOP ID

    Faça login com sua conta de SSO HOP ID em toda a família HOP, ou utilize o PixelHop como visitante.

  • Álbuns e compartilhamento em lote

    Envie múltiplas imagens em uma galeria responsiva, copie todos os links com um clique ou baixe um arquivo ZIP consolidado.

  • Links com expiração e privados

    Defina prazos de autodestruição (10 minutos, 24 horas, 30 dias) ou proteja com senha. Visitantes recebem tokens de exclusão privados.

  • ShareX e API REST

    Configurações prontas para ShareX, envio por linha de comando com pixelhop push e tokens de API pessoais.

  • Binário único em Go para auto-hospedagem

    Executável Go leve de ~16 MB com SQLite integrado, compatível com disco local ou armazenamento S3.

Auto-hospedagem

O PixelHop pode ser hospedado por você. Compile e execute o binário único em segundos:

git clone https://github.com/navi-crwn/PixelHop.git
cd PixelHop
go build -o pixelhop ./cmd/pixelhop
./pixelhop

Requisitos

Go 1.22+ e SQLite. Instruções completas de início rápido, Docker e testes no README do GitHub.

Configuração de login

O login utiliza o SSO HOP ID. Configure HOP_HUB_URL, HOP_APP=pixelhop e HOP_SSO_SECRET no seu ambiente antes de entrar, ou opere em modo independente.

Banco de Dados e Armazenamento

O PixelHop utiliza SQLite integrado com armazenamento em disco local por padrão. Configure variáveis S3 para buckets em nuvem.

Os modos independente e SSO são totalmente suportados em instalações próprias.

Perguntas frequentes

O PixelHop reduz a qualidade da minha imagem?

Não. A remoção de metadados limpa cabeçalhos EXIF e GPS reescrevendo o arquivo sem recodificar os pixels, mantendo a fidelidade original.

Preciso de conta para enviar imagens?

Não. O envio para visitantes é suportado com tokens de exclusão privados. O login com HOP ID libera galerías pessoais e chaves de API.

Posso hospedar o PixelHop no meu servidor?

Sim. O PixelHop compila em um único executável Go sem dependências externas de runtime. Veja o README do repositório.

Onde posso relatar falhas ou vulnerabilidades?

Abra uma issue no GitHub ou escreva para security@hel.ink para divulgação responsável.
