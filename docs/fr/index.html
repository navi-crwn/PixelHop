HOP · Hébergement d’images et studio photo

Déposez une image, nettoyez les métadonnées, partagez en quelques secondes

PixelHop offre des téléversements rapides, des albums photos et un studio d’édition privé directement dans votre navigateur. Liens courts et propres sur p.hel.ink et tableau de bord sur pixel.hel.ink. Binaire Go unique, auto-hébergeable, open source (MIT).

Ce que propose PixelHop

  • Téléversement rapide et liens propres

    Glissez vos photos ou captures d’écran pour obtenir des liens courts sur p.hel.ink/{slug}, liens directs, Markdown et codes d’intégration.

  • Métadonnées nettoyées par défaut

    Les coordonnées GPS, numéros de série et métadonnées EXIF sont retirés par réécriture du conteneur sans recomprimer les pixels.

  • Studio photo privé dans le navigateur

    Compressez, redimensionnez, recadrez, convertissez en WebP/AVIF, floutez les détails sensibles et lancez l’OCR localement sans téléverser l’image.

  • Connexion unique : HOP ID

    Connectez-vous avec votre compte SSO HOP ID sur l’ensemble de la famille HOP, ou utilisez PixelHop en mode invité.

  • Albums et partage groupé

    Téléversez plusieurs photos dans une galerie responsive, copiez tous les liens en un clic ou téléchargez une archive ZIP groupée.

  • Liens éphémères et privés

    Définissez des délais d’autodestruction (10 minutes, 24 heures, 30 jours) ou protégez par mot de passe. Les invités reçoivent un jeton de suppression.

  • ShareX et API REST

    Profils ShareX prêts à l’emploi, envoi en ligne de commande avec pixelhop push et jetons d’API personnels.

  • Binaire Go unique auto-hébergeable

    Binaire autonome léger (~16 Mo) avec SQLite intégré, compatible avec stockage disque local ou compartiments S3.

Auto-hébergement

PixelHop est auto-hébergeable. Compilez et lancez le binaire en quelques secondes :

git clone https://github.com/navi-crwn/PixelHop.git
cd PixelHop
go build -o pixelhop ./cmd/pixelhop
./pixelhop

Prérequis

Go 1.22+ et SQLite. Le guide complet, les commandes Docker et les tests sont disponibles sur le README GitHub.

Configuration de connexion

La connexion s’effectue avec le SSO HOP ID. Configurez HOP_HUB_URL, HOP_APP=pixelhop et HOP_SSO_SECRET dans votre environnement avant de vous connecter.

Base de données et stockage

PixelHop utilise par défaut une base SQLite intégrée et le stockage sur disque local. Configurez les variables S3 pour le stockage cloud.

Les modes autonome et SSO sont pleinement pris en charge en auto-hébergement.

FAQ

PixelHop altère-t-il la qualité de mon image ?

Non. Le nettoyage des métadonnées retire les en-têtes EXIF et GPS sans réencoder les pixels, préservant la fidélité de l’image.

Dois-je créer un compte pour envoyer des images ?

Non. L’envoi en mode invité est disponible avec un jeton de suppression privé. La connexion avec HOP ID active les albums personnels et clés API.

Puis-je héberger PixelHop sur mon propre serveur ?

Oui. PixelHop se compile en un unique binaire autonome en Go sans dépendances externes. Consultez le README du dépôt.

Où signaler un problème ou une faille de sécurité ?

Ouvrez un ticket sur GitHub ou écrivez à security@hel.ink pour une divulgation responsable.
