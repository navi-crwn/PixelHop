Recursos

Tudo o que uma hospedagem de imagens deve fazer. Nada do que não deve.

Nenhum plano premium escondendo as partes boas. Toda conta tem todos os recursos.

Localização removida, qualidade mantida

Fotos de celular trazem coordenadas GPS e números de série da câmera. O PixelHop remove EXIF, XMP e IPTC reescrevendo o contêiner do arquivo, então os pixels nunca são recomprimidos, e antes endireita fotos tiradas de lado.

Todos os links de que você precisa

Links legíveis como beach-sunset-x7Kp2Q, um link direto, Markdown, HTML, BBCode e um QR code. As prévias ficam certinhas no Discord, X, WhatsApp e fóruns.

Álbuns

Solte várias fotos e compartilhe todas com um único link de galeria.

Autodestruição

Apagar depois de 10 minutos, um dia ou um mês. Visitantes recebem um link privado para apagar.

ShareX & API

Configuração do ShareX em um clique, API REST com chaves. Configurações antigas do PixelHop 2 continuam funcionando.

Hospede você mesmo

Um binário, imagem Docker ou systemd. Disco, R2, MinIO, B2, Contabo.

Moderação embutida

Denúncias, ocultar/apagar, bloqueio de IP, bloquear ou suspender contas, avisos.

Copie todos os links de uma vez

Depois de um envio em lote: todos os links diretos, de página, Markdown, BBCode ou HTML em um clique. Galerias também em ZIP.

Privado ou com senha

Por imagem: qualquer pessoa com o link, só você, ou protegido por senha. Arquivos bloqueados não podem ser usados em hotlink.

Redimensione pela URL, veja estatísticas

?w=800&format=webp gera qualquer tamanho. Donos veem as visualizações por dia e quais sites fazem link para eles.

App instalável, HEIC, marca d’água

Adicione à tela inicial e compartilhe fotos direto para ele. O HEIC do iPhone é convertido sozinho. Coloque marca d’água em uma imagem ou em um lote inteiro.

Webhooks assinados, incorporações para WordPress e Notion, um feed Explore e pixelhop push no terminal.

Studio

Um estúdio de fotos que nunca envia sua foto.

A maioria das ferramentas roda no seu próprio dispositivo com Canvas e WebAssembly, então a imagem só sai dele se você tocar em “Enviar resultado”. As ferramentas de IA mais pesadas rodam no servidor, para membros, e não guardam nada.

  • Comprimir, redimensionar, recortar, converter para JPG, PNG, WebP ou AVIF, com o tamanho do arquivo ao vivo.
  • Ajustar e girar: luz, contraste, cor, preto e branco, espelhar.
  • Desfocar e pixelar rostos, placas e nomes antes de compartilhar.
  • Imagem para texto (OCR) em 30 idiomas, vários ao mesmo tempo na mesma imagem.
  • Remover fundo com um modelo de IA que roda no navegador.
  • Paleta de cores e um gerador de QR code (PNG ou SVG).
  • No servidor, para membros: remoção de fundo em um segundo, desfoque automático de rostos, uma borracha mágica e ampliação HD 2×. Processado na memória, nunca armazenado.
  • Em lote: aplique os mesmos passos em muitas imagens e receba um ZIP ou um álbum.

Auto-hospedar

Rodando em um minuto.

Sem PHP, sem Python, sem MySQL, sem cron. A primeira conta que você criar vira a de administrador.

# Linux (amd64). Versões para arm64, macOS e Windows estão na página de Releases.
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

FAQ

Perguntas

É grátis?

Sim. O p.hel.ink é gratuito, e o código tem licença MIT, então você pode rodar sua própria cópia, inclusive comercialmente.

Preciso de uma conta?

Não. Visitantes podem enviar imagens e recebem um link privado para apagar cada uma (também salvo no navegador). Uma conta acrescenta uma galeria, uma cota de armazenamento visível e chaves de API.

O estúdio é privado?

A maioria das ferramentas roda no seu dispositivo e nunca envia a imagem para lugar nenhum. As ferramentas de IA marcadas como “servidor” (remoção rápida de fundo, desfoque de rostos, borracha mágica, ampliação HD) enviam a imagem para o servidor que você está usando, processam na memória e descartam; você escolhe quando usá-las.

Que armazenamento posso usar?

O disco local ou qualquer bucket compatível com S3: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Defina S3_PUBLIC_URL para servir as imagens direto de uma CDN.

Como denuncio uma imagem?

Toda página de imagem tem um botão Denunciar. As denúncias vão direto para a fila dos moderadores, que podem ocultar ou apagar a imagem e bloquear quem enviou.

Por que Go?

Uma hospedagem de imagens passa o tempo movendo bytes. O Go faz isso com pouca memória, compila para um único arquivo com tudo dentro e faz compilação cruzada para qualquer servidor. O PixelHop 2 precisava de PHP, MySQL, Python e cron; o PixelHop 3 só precisa de si mesmo.
