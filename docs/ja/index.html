画像をドロップ。
リンクをゲット。

誰かに見られる前に GPS 位置情報を削除するオープンソースの画像ホスティング。アルバム、ShareX、API、そして写真を一切アップロードしないフォトスタジオを備えています。

画像をアップロード コードを入手
  • 約 16 MB のシングルバイナリ
  • SQLite 内蔵、データベースサーバー不要
  • ディスクまたは任意の S3 バケット
  • 広告なし、トラッカーなし
pixel.hel.ink
機能

画像ホストがすべきことは全部。すべきでないことは何も。

良い機能を隠す有料プランはありません。すべてのアカウントですべての機能が使えます。

位置情報は削除、画質はそのまま

スマホの写真には GPS 座標やカメラのシリアル番号が含まれます。PixelHop はファイルのコンテナを書き換えて EXIF、XMP、IPTC を削除するため、ピクセルが再圧縮されることはありません。横向きの写真は先に正しい向きに直します。

必要なリンクがすべて

beach-sunset-x7Kp2Q のような読みやすいリンク、直リンク、Markdown、HTML、BBCode、QR コード。Discord、X、WhatsApp、掲示板でもプレビューがきれいに表示されます。

アルバム

複数の写真をドロップして、1 つのギャラリーリンクで共有。

自動削除

10 分後、1 日後、1 か月後に削除。ゲストには専用の削除リンクが発行されます。

ShareX & API

ワンクリックで ShareX 設定、キー付きの REST API。旧 PixelHop 2 の設定もそのまま使えます。

自分でホスト

バイナリ 1 つ、Docker イメージ、または systemd。ディスク、R2、MinIO、B2、Contabo に対応。

モデレーション機能内蔵

通報、非表示・削除、IP ブロック、アカウントのロック・停止、警告。

すべてのリンクを一度にコピー

一括アップロード後、直リンク、ページ、Markdown、BBCode、HTML のリンクをワンクリックでまとめてコピー。ギャラリーの ZIP ダウンロードにも対応。

非公開またはパスワード保護

画像ごとに設定：リンクを知っている人、自分だけ、またはパスワード付き。ロックしたファイルは直リンクできません。

URL でリサイズ、閲覧統計

?w=800&format=webp で任意のサイズに。所有者は 1 日ごとの閲覧数と、どのサイトからリンクされているかを確認できます。

アプリとしてインストール、HEIC、透かし

ホーム画面に追加すれば、写真をそのまま共有できます。iPhone の HEIC は自動で変換。1 枚にもまとめてにも透かしを入れられます。

Webhook、oEmbed、CLI

署名付き Webhook、WordPress や Notion への埋め込み、Explore フィード、そしてターミナルからの pixelhop push。

HEL.ink とアカウントを共通化

p.hel.ink では HEL.ink のアカウントでサインインします。短縮リンク、プロフィールページ、画像で同じログインを使え、Google ログインと 2 段階認証にも対応。セルフホストではオフにできます。

古いリンクもそのまま動作

PixelHop 2 のページ、直リンク、サムネイルのリンク、さらに ShareX の設定やアップロード結果ページも、以前とまったく同じように動きます。

Studio

写真を一切アップロードしないフォトスタジオ。

ほとんどのツールは Canvas と WebAssembly であなたの端末上で動くため、「結果をアップロード」を押さない限り画像が端末の外に出ることはありません。重い AI ツールは会員向けにサーバーで動き、何も保存しません。

  • JPG、PNG、WebP、AVIF への圧縮・リサイズ・切り抜き・変換。ファイルサイズをその場で表示。
  • 補正と回転：明るさ、コントラスト、色、白黒、反転。
  • 共有する前に、顔やナンバープレート、名前をぼかし・モザイク。
  • 画像からテキスト（OCR）。30 言語に対応し、1 枚の画像の中の複数言語をまとめて読み取れます。
  • ブラウザ内で動く AI モデルで背景を削除。
  • カラーパレットとQR コード生成（PNG または SVG）。
  • サーバー上で、会員向けに：1 秒で背景削除、顔の自動ぼかし、マジック消しゴム、2 倍の HD アップスケール。メモリ上で処理し、保存はしません。
  • 一括処理：多数の画像に同じ手順を適用し、ZIP 1 つまたはアルバム 1 つで受け取れます。

セルフホスト

1 分で起動。

PHP も Python も MySQL も cron も不要。最初に作ったアカウントが管理者になります。

# Linux（amd64）。arm64、macOS、Windows 版は Releases ページにあります。
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

アップグレード

PixelHop 2 からの移行ですか？

コマンド 1 つでユーザーと画像を移行できます。パスワード、ページのリンク、/i/… のリンク、ShareX の設定はそのまま使えます。

pixelhop import --images /var/www/pichost/data/images.json \
  --mysql "user:pass@tcp(127.0.0.1)/pixelhop" --copy

API

どこからでもアップロード。

設定でキーを作成し、任意の HTTP クライアントでファイルを送るだけ。応答は直リンク、ページリンク、サムネイル、埋め込みコードを含むシンプルな JSON です。

API ドキュメント

curl -H "Authorization: Bearer ph_yourkey" \
     -F "file=@holiday.jpg" -F "expire=7d" \
     https://pixel.hel.ink/api/v1/upload
// 200 OK

FAQ

よくある質問

無料ですか？

はい。p.hel.ink は無料で使え、コードは MIT ライセンスなので、商用でも自分のコピーを運用できます。

アカウントは必要ですか？

いいえ。ゲストもアップロードでき、画像ごとに専用の削除リンク（ブラウザにも保存）を受け取れます。アカウントがあれば、ギャラリー、確認できるストレージ容量、API キーが使えます。

スタジオはプライベートですか？

ほとんどのツールはあなたの端末上で動き、画像をどこにも送りません。「サーバー」と表示された AI ツール（高速な背景削除、顔ぼかし、マジック消しゴム、HD アップスケール）は、利用中のサーバーに画像を送り、メモリ上で処理して破棄します。使うかどうかはあなたが選べます。

どのストレージが使えますか？

ローカルディスク、または S3 互換の任意のバケット：AWS S3、Cloudflare R2、MinIO、Backblaze B2、Wasabi、Contabo。S3_PUBLIC_URL を設定すれば CDN から直接配信できます。

画像を通報するには？

すべての画像ページに通報ボタンがあります。通報はモデレーターのキューに直接届き、画像の非表示や削除、アップロードした人のブロックができます。

なぜ Go なのか？

画像ホストはほとんどの時間をバイトの転送に使います。Go は少ないメモリでそれをこなし、すべてを含んだ 1 つのファイルにコンパイルでき、どんなサーバー向けにもクロスコンパイルできます。PixelHop 2 には PHP、MySQL、Python、cron が必要でしたが、PixelHop 3 は自分自身だけで動きます。
