HOP · 画像ホスティング＆フォトスタジオ

画像をドロップ、メタデータを消去、瞬時にシェア

PixelHop は高速な画像アップロード、アルバムギャラリー、ブラウザ完結のフォトスタジオを提供します。p.hel.ink で短いリンクを発行し、pixel.hel.ink で管理。Go言語の単一バイナリ、セルフホスト可能、オープンソース（MIT）。

PixelHop を試す 画像を探索 コードを見る

ページ内のリンクはHOPファミリーの公開サイトへ接続します。

PixelHop の機能

  • 高速アップロードとクリーンなリンク

    写真やスクリーンショットをドロップして、p.hel.ink/{slug} の短縮URL、直リンク、Markdown、埋め込みコードを取得。

  • 位置情報・メタデータを自動除去

    GPS座標や端末シリアル、EXIF情報をコンテナ再構成により除去。元のピクセルを再圧縮しません。

  • ブラウザ完結のフォトスタジオ

    圧縮、リサイズ、切り抜き、WebP/AVIF変換、モザイク処理、OCR文字認識をアップロード前にお使いの端末内で完結。

  • 全アプリ共通サインイン：HOP ID

    HOP ID シングルサインオンでHOPファミリー全体をシームレスに利用可能。ゲスト利用もサポート。

  • アルバムと一括共有

    複数画像を一度にアップロードしてレスポンシブなギャラリーを作成。ワンクリックで全リンクをコピー、またはZIP一括保存。

  • 自動消滅リンクとパスワード保護

    自動消滅タイマー（10分、24時間、30日）や閲覧パスワードを設定可能。ゲストには専用の削除キーを発行。

  • ShareX と REST API 対応

    ShareX の即時設定ファイル、pixelhop push コマンド、自動化用パーソナルAPIトークンを標準装備。

  • Go単一バイナリでのセルフホスト

    約16MBの軽量Goバイナリ1つと内蔵SQLiteで動作。ローカルディスクおよびS3互換ストレージに対応。

セルフホスト

PixelHop はご自身で運用可能です。単一バイナリのビルドと起動手順：

git clone https://github.com/navi-crwn/PixelHop.git
cd PixelHop
go build -o pixelhop ./cmd/pixelhop
./pixelhop

動作要件

Go 1.22+ および SQLite。クイックスタート、Dockerコマンド、テスト詳細は GitHub の README をご覧ください。

サインイン設定

サインインは HOP ID SSO を利用します。環境変数 HOP_HUB_URL、HOP_APP=pixelhop、HOP_SSO_SECRET を設定するか、スタンドアロンモードで運用してください。

データベースとストレージ

標準で内蔵SQLiteとローカルディスクストレージを使用します。クラウド利用時はS3環境変数を指定してください。

セルフホスト運用においてスタンドアロンモードとSSOモードの両方を完全サポートしています。

よくある質問

PixelHop は画像の画質を圧縮・劣化させますか？

いいえ。メタデータの除去はファイル構造の書き換えのみで行われ、画像ピクセルの再エンコードは行われません。

画像のアップロードにアカウントは必須ですか？

いいえ。ゲストアップロードにも対応しており、削除用キーが発行されます。HOP ID でログインするとギャラリー管理や永続APIキーが使えます。

自分のサーバーでホストできますか？

はい。外部ランタイム不要の単一バイナリとしてコンパイルされます。詳細はリポジトリの README をご覧ください。

不具合やセキュリティ報告はどこへ連絡すればよいですか？

GitHub の Issue、または security@hel.ink 宛にご連絡ください。責任ある情報開示に対応しています。
