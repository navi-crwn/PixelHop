Funktionen

Alles, was ein Bildhoster können sollte. Nichts, was er nicht sollte.

Kein Premium-Tarif, der die guten Funktionen versteckt. Jedes Konto bekommt alle Funktionen.

Standort entfernt, Qualität bleibt

Handyfotos enthalten GPS-Koordinaten und Kamera-Seriennummern. PixelHop entfernt EXIF, XMP und IPTC, indem es den Dateicontainer neu schreibt – die Pixel werden also nie neu komprimiert – und dreht gekippte Fotos vorher richtig herum.

Jeder Link, den du brauchst

Lesbare Links wie beach-sunset-x7Kp2Q, ein Direktlink, Markdown, HTML, BBCode und ein QR-Code. Vorschauen sehen auf Discord, X, WhatsApp und in Foren richtig aus.

Alben

Mehrere Fotos ablegen und als einen Galerie-Link teilen.

Selbstzerstörung

Löschen nach 10 Minuten, einem Tag oder einem Monat. Gäste bekommen einen privaten Lösch-Link.

ShareX & API

ShareX-Konfiguration mit einem Klick, REST-API mit Schlüsseln. Alte PixelHop-2-Konfigurationen funktionieren weiter.

Selbst hosten

Eine Binary, ein Docker-Image oder systemd. Festplatte, R2, MinIO, B2, Contabo.

Moderation eingebaut

Meldungen, Ausblenden/Löschen, IP-Sperren, Konten sperren oder suspendieren, Verwarnungen.

Alle Links auf einmal kopieren

Nach einem Massen-Upload: alle Direkt-, Seiten-, Markdown-, BBCode- oder HTML-Links mit einem Klick. Galerien auch als ZIP-Download.

Privat oder mit Passwort

Pro Bild: jeder mit dem Link, nur du oder hinter einem Passwort. Gesperrte Dateien lassen sich nicht hotlinken.

Größe per URL, Aufrufstatistik

?w=800&format=webp erzeugt jede Größe. Besitzer sehen die Aufrufe pro Tag und welche Seiten auf sie verlinken.

Installierbare App, HEIC, Wasserzeichen

Zum Startbildschirm hinzufügen und Fotos direkt dorthin teilen. iPhone-HEIC wird automatisch umgewandelt. Wasserzeichen für ein Bild oder einen ganzen Stapel.

Webhooks, oEmbed, CLI

Signierte Webhooks, Einbettungen für WordPress und Notion, ein Explore-Feed und pixelhop push im Terminal.

Ein Konto mit HEL.ink

Auf p.hel.ink meldest du dich mit deinem HEL.ink-Konto an: dieselbe Anmeldung für Kurzlinks, Bio-Seiten und Bilder, mit Google-Login und Zwei-Faktor-Codes. Beim Selbsthosten lässt sich das abschalten.

Studio

Ein Fotostudio, das dein Foto nie hochlädt.

Die meisten Werkzeuge laufen mit Canvas und WebAssembly auf deinem eigenen Gerät; das Bild verlässt es nur, wenn du auf „Ergebnis hochladen“ drückst. Die aufwendigen KI-Werkzeuge laufen für Mitglieder auf dem Server und speichern nichts.

  • Komprimieren, skalieren, zuschneiden, umwandeln in JPG, PNG, WebP oder AVIF, mit Live-Dateigröße.
  • Anpassen & drehen: Helligkeit, Kontrast, Farbe, Schwarzweiß, spiegeln.
  • Weichzeichnen & verpixeln von Gesichtern, Kennzeichen und Namen, bevor du teilst.
  • Bild zu Text (OCR) in 30 Sprachen, auch mehrere gemischt im selben Bild.
  • Hintergrund entfernen mit einem KI-Modell, das im Browser läuft.
  • Farbpalette und ein QR-Code-Generator (PNG oder SVG).
  • Auf dem Server, für Mitglieder: Hintergrund entfernen in einer Sekunde, automatisches Gesichter-Weichzeichnen, ein magischer Radierer und HD-Hochskalierung 2×. Im Arbeitsspeicher verarbeitet, nie gespeichert.
  • Stapel: dieselben Schritte auf viele Bilder anwenden und ein ZIP oder ein Album bekommen.

Selbst hosten

Läuft in einer Minute.

Kein PHP, kein Python, kein MySQL, kein Cron. Das erste Konto, das du anlegst, wird Administrator.

# Linux (amd64). Builds für arm64, macOS und Windows gibt es auf der Releases-Seite.
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

API

Hochladen von überall.

Erstelle in den Einstellungen einen Schlüssel und sende Dateien mit einem beliebigen HTTP-Client. Die Antworten sind einfaches JSON mit Direktlink, Seitenlink, Vorschaubild und Einbettungscodes.

FAQ

Fragen

Ist es kostenlos?

Ja. p.hel.ink ist kostenlos nutzbar, und der Code steht unter der MIT-Lizenz – du kannst also deine eigene Instanz betreiben, auch kommerziell.

Brauche ich ein Konto?

Nein. Gäste können hochladen und bekommen für jedes Bild einen privaten Lösch-Link (auch im Browser gespeichert). Ein Konto bietet zusätzlich eine Galerie, ein sichtbares Speicherkontingent und API-Schlüssel.

Ist das Studio privat?

Die meisten Werkzeuge laufen auf deinem Gerät und senden das Bild nirgendwohin. Die als „Server“ markierten KI-Werkzeuge (schnelle Hintergrundentfernung, Gesichter-Weichzeichnen, magischer Radierer, HD-Hochskalierung) schicken es an den Server, den du nutzt, verarbeiten es im Arbeitsspeicher und verwerfen es; du entscheidest, wann du sie nutzt.

Welchen Speicher kann ich nutzen?

Die lokale Festplatte oder jeden S3-kompatiblen Bucket: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Setze S3_PUBLIC_URL, um Bilder direkt über ein CDN auszuliefern.

Wie melde ich ein Bild?

Jede Bildseite hat einen Melden-Button. Meldungen landen direkt in der Warteschlange der Moderatoren, die das Bild ausblenden oder löschen und den Uploader sperren können.

Warum Go?

Ein Bildhoster verbringt seine Zeit damit, Bytes zu bewegen. Go erledigt das mit wenig Arbeitsspeicher, kompiliert zu einer Datei mit allem darin und lässt sich für jeden Server cross-kompilieren. PixelHop 2 brauchte PHP, MySQL, Python und Cron; PixelHop 3 braucht nur sich selbst.
