HOP · Image hosting & photo studio

Drop an image, strip metadata, share in seconds

PixelHop delivers fast image uploads, album galleries, and a private browser-based photo studio. Clean short links live at p.hel.ink and your dashboard at pixel.hel.ink. Single Go binary, self-hostable, open source (MIT).

What PixelHop does

  • Fast uploads & clean links

    Drop photos, screenshots, or artwork to get readable short links at p.hel.ink/{slug}, direct image links, Markdown, and embed codes.

  • Metadata stripped by default

    GPS coordinates, device serials, and EXIF tags are stripped by rewriting the container so original pixels are never re-compressed.

  • Private browser photo studio

    Compress, resize, crop, convert to WebP/AVIF, blur sensitive details, and run OCR directly in your browser without uploading first.

  • One sign-in for every app: HOP ID

    Sign in seamlessly with your HOP ID single sign-on account across the entire HOP family, or use PixelHop as a guest.

  • Albums & bulk sharing

    Upload multiple images at once into a responsive gallery, copy all links in one click, or download a consolidated ZIP archive.

  • Expiring & private links

    Set self-destruct timers (10 minutes, 24 hours, 30 days) or password-protect sensitive shares. Guests receive private deletion tokens.

  • ShareX & REST API

    First-class ShareX destination configs, CLI uploading via pixelhop push, and personal API tokens for headless workflows.

  • Single Go binary self-hosting

    Runs as a lightweight ~16 MB Go executable with embedded SQLite and supports local disk or any S3-compatible object storage.

Run your own

PixelHop is self-hostable. Build and run the single binary in seconds:

git clone https://github.com/navi-crwn/PixelHop.git
cd PixelHop
go build -o pixelhop ./cmd/pixelhop
./pixelhop

Prerequisites

Go 1.22+ and SQLite. Full quickstart, Docker commands, and test suites are in the README on GitHub.

Sign-in configuration

Sign-in uses HOP ID single sign-on. Set HOP_HUB_URL, HOP_APP=pixelhop, and HOP_SSO_SECRET in your environment before signing in, or run in standalone mode.

Database & Storage

PixelHop defaults to an embedded SQLite database with local disk storage. Set S3 environment variables for cloud bucket storage.

Standalone and single sign-on modes are fully supported in self-hosted deployments.

FAQ

Does PixelHop recompress or alter my image quality?

No. Metadata stripping removes EXIF and GPS headers by rewriting file containers without re-encoding pixels, preserving original visual fidelity.

Do I need an account to upload images?

No. Guest uploads are fully supported with private deletion tokens. Signing in with HOP ID unlocks personal galleries and persistent API keys.

Can I host PixelHop on my own server?

Yes. PixelHop compiles into a single standalone Go binary with zero external runtime dependencies. See the repository README for setup instructions.

Where do I report bugs or security issues?

Open an issue on GitHub or email security@hel.ink for responsible vulnerability disclosure.
