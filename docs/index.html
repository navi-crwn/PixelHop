Studio

A photo studio that never uploads your photo.Studio foto yang tidak pernah mengunggah fotomu.

Most tools run on your own device with Canvas and WebAssembly, so the image only leaves it if you press “Upload result”. The heavy AI tools run on the server, for members, and keep nothing.Sebagian besar alat jalan di perangkatmu sendiri dengan Canvas dan WebAssembly, jadi gambar baru keluar kalau kamu menekan “Upload result”. Alat AI yang berat jalan di server, untuk member, dan tidak menyimpan apa pun.

  • Compress, resize, crop, convert to JPG, PNG, WebP or AVIF, with live file size.Kompres, ubah ukuran, crop, konversi ke JPG, PNG, WebP atau AVIF, ukuran file langsung terlihat.
  • Adjust & rotate: light, contrast, color, black & white, flip.Atur & putar: terang, kontras, warna, hitam putih, balik.

  • Image to text (OCR) in English, Indonesian, Japanese, Chinese, Korean, Arabic.Gambar ke teks (OCR) dalam bahasa Inggris, Indonesia, Jepang, Mandarin, Korea, Arab.

FAQ

QuestionsPertanyaan

Is it free?Gratis?

Yes. p.hel.ink is free to use, and the code is MIT-licensed, so you can run your own copy, even commercially.Ya. p.hel.ink gratis dipakai, dan kodenya berlisensi MIT, jadi kamu bisa menjalankan versimu sendiri, bahkan untuk komersial.

Do I need an account?Perlu akun?

No. Guests can upload and get a private delete link for each image (saved in their browser too). An account adds a gallery, a storage quota you can see, and API keys.Tidak. Tamu bisa mengunggah dan mendapat link hapus pribadi untuk setiap gambar (juga tersimpan di browser). Dengan akun kamu dapat galeri, kuota yang terlihat, dan API key.

Is the studio private?Apakah studio privat?

Most tools run on your device and never send the image anywhere. The AI tools marked “server” (fast background removal, face blur, magic eraser, HD upscale) send it to the server you're using, process it in memory and discard it; you choose when to use them.Sebagian besar alat jalan di perangkatmu dan tidak mengirim gambar ke mana pun. Alat AI bertanda “server” (hapus background cepat, blur wajah, magic eraser, HD upscale) mengirimnya ke server, memprosesnya di memori lalu membuangnya; kamu yang memilih kapan memakainya.

Which storage can I use?Storage apa saja yang bisa dipakai?

The local disk, or any S3-compatible bucket: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Set S3_PUBLIC_URL to serve images straight from a CDN.Disk lokal, atau bucket S3 apa saja: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Isi S3_PUBLIC_URL untuk menyajikan gambar langsung dari CDN.

How do I report an image?Bagaimana melaporkan gambar?

Every image page has a Report button. Reports go straight to the moderators' queue, where they can hide or delete the image and ban the uploader.Setiap halaman gambar punya tombol Report. Laporan langsung masuk antrean moderator, yang bisa menyembunyikan atau menghapus gambar dan memblokir pengunggahnya.

Why Go?Kenapa Go?

An image host spends its time moving bytes. Go does that with little memory, compiles to one file with everything inside, and cross-compiles to any server. PixelHop 2 needed PHP, MySQL, Python and cron; PixelHop 3 needs nothing but itself.Image host sebagian besar waktunya memindahkan byte. Go melakukannya dengan memori kecil, dikompilasi jadi satu file berisi semuanya, dan bisa dibuat untuk server apa pun. PixelHop 2 butuh PHP, MySQL, Python dan cron; PixelHop 3 tidak butuh apa-apa selain dirinya sendiri.
