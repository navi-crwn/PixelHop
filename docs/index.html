Features

Everything an image host should do. Nothing it shouldn’t.

No premium tier hiding the good parts. Every account gets every feature.

Location removed, quality kept

Phone photos carry GPS coordinates and camera serials. PixelHop removes EXIF, XMP and IPTC by rewriting the file container, so the pixels are never re-compressed, and turns sideways photos upright first.

Every link you need

Readable links like beach-sunset-x7Kp2Q, a direct link, Markdown, HTML, BBCode and a QR code. Previews look right on Discord, X, WhatsApp and forums.

Albums

Drop several photos and share them as one gallery link.

Self-destruct

Delete after 10 minutes, a day or a month. Guests get a private delete link.

ShareX & API

One-click ShareX config, REST API with keys. Old PixelHop 2 configs keep working.

Host it yourself

One binary, Docker image or systemd. Disk, R2, MinIO, B2, Contabo.

Moderation built in

Reports, hide/delete, IP bans, lock or suspend accounts, warnings.

Copy every link at once

After a bulk upload: all direct, page, Markdown, BBCode or HTML links in one click. Gallery ZIP downloads too.

Private or password-protected

Per image: anyone with the link, only you, or behind a password. Locked files can't be hotlinked.

Resize by URL, view stats

?w=800&format=webp makes any size. Owners see views per day and which sites link to them.

Installable app, HEIC, watermark

Add it to your home screen and share photos to it. iPhone HEIC converts itself. Watermark one image or a whole batch.

Webhooks, oEmbed, CLI

Signed webhooks, embeds for WordPress and Notion, an Explore feed, and pixelhop push from the terminal.

One account with HEL.ink

On p.hel.ink you sign in with your HEL.ink account: the same login for short links, bio pages and images, with Google sign-in and two-factor codes. Self-hosters can leave it off.

Old links keep working

Every page, direct and thumbnail link from PixelHop 2, plus its ShareX configs and upload result pages, answers exactly as before.

Studio

A photo studio that never uploads your photo.

Most tools run on your own device with Canvas and WebAssembly, so the image only leaves it if you press “Upload result”. The heavy AI tools run on the server, for members, and keep nothing.

  • Compress, resize, crop, convert to JPG, PNG, WebP or AVIF, with live file size.
  • Adjust & rotate: light, contrast, color, black & white, flip.
  • Blur & pixelate faces, plates and names before you share.
  • Image to text (OCR) in six languages, including English, Chinese, Japanese, Korean and Arabic.
  • Remove background with an AI model that runs in the browser.
  • Color palette and a QR code generator (PNG or SVG).
  • On the server, for members: background removal in a second, automatic face blur, a magic eraser and HD upscale 2×. Processed in memory, never stored.
  • Batch: run the same steps on many images, then get one ZIP or one album.

Self-host

Running in one minute.

No PHP, no Python, no MySQL, no cron. The first account you create becomes the admin.

# Linux (amd64). Builds for arm64, macOS and Windows are on the Releases page.
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

FAQ

Questions

Is it free?

Yes. p.hel.ink is free to use, and the code is MIT-licensed, so you can run your own copy, even commercially.

Do I need an account?

No. Guests can upload and get a private delete link for each image (saved in their browser too). An account adds a gallery, a storage quota you can see, and API keys.

Is the studio private?

Most tools run on your device and never send the image anywhere. The AI tools marked “server” (fast background removal, face blur, magic eraser, HD upscale) send it to the server you're using, process it in memory and discard it; you choose when to use them.

Which storage can I use?

The local disk, or any S3-compatible bucket: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Set S3_PUBLIC_URL to serve images straight from a CDN.

How do I report an image?

Every image page has a Report button. Reports go straight to the moderators' queue, where they can hide or delete the image and ban the uploader.

Why Go?

An image host spends its time moving bytes. Go does that with little memory, compiles to one file with everything inside, and cross-compiles to any server. PixelHop 2 needed PHP, MySQL, Python and cron; PixelHop 3 needs nothing but itself.
