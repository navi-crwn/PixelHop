أفلت صورتك، وتخلص من البيانات الوصفية، وشاركها في ثوانٍ

يوفر PixelHop رفعاً فائق السرعة للصور، ومعارض للألبومات، واستوديو صور خاص يعمل مباشرة داخل المتصفح. روابط قصيرة نظيفة على p.hel.ink ولوحة تحكمك على pixel.hel.ink. ملف تنفيذي واحد بلغة Go، استضافة ذاتية، ومفتوح المصدر (MIT).

ما يقدمه PixelHop

  • رفع سريع وروابط نظيفة

    اسحب الصور ولقطات الشاشة للحصول على روابط قصيرة على p.hel.ink/{slug}، وروابط مباشرة، وكود Markdown وتضمين.

  • إزالة البيانات الوصفية افتراضياً

    تُحذف إحداثيات GPS والأرقام التسلسلية وبيانات EXIF عبر إعادة صياغة حاوية الملف دون إعادة ضغط البكسلات الأصلية.

  • استوديو صور خاص بالمتصفح

    ضغط وتغيير حجم وقص وتحويل إلى WebP/AVIF وتشويش الوجوه والتعرف على النصوص مباشرة في متصفحك دون رفع الصورة مسبقاً.

  • تسجيل دخول موحد: HOP ID

    سجل الدخول بسهولة عبر حساب HOP ID الموحد عبر جميع تطبيقات HOP، أو استخدم PixelHop كزائر.

  • ألبومات ومشاركة دفعات

    ارفع صوراً متعددة دفعة واحدة في معرض متجاوب، وانسخ كل الروابط بنقرة واحدة، أو حمل أرشيف ZIP مدمج.

  • روابط مؤقتة وخاصة

    حدد مؤقتات التدمير الذاتي (10 دقائق، 24 ساعة، 30 يوماً) أو احمِ الروابط بكلمة سر. يحصل الزوار على رموز حذف خاصة.

  • دعم ShareX وواجهة برمجة التطبيقات REST

    إعدادات جاهزة لـ ShareX، ورفع عبر سطر الأوامر بواسطة pixelhop push، ومفاتيح API لعمليات الأتمتة.

  • ملف تنفيذي واحد بلغة Go

    يعمل كملف Go خفيف بحجم ~16 ميغابايت مع SQLite مدمج، ويدعم القرص المحلي أو أي مساحة تخزين متوافقة مع S3.

الأسئلة الشائعة

هل يقوم PixelHop بضغط الصورة أو تقليل جودتها؟

كلا. يؤدي تجريد البيانات الوصفية إلى إزالة ترويسات EXIF و GPS عن طريق إعادة كتابة حاوية الملف دون إعادة تشفير البكسلات الأصلية.

هل يلزمني حساب لرفع الصور؟

كلا. الرفع للزوار مدعوم بالكامل مع توفير رمز حذف خاص. تسجيل الدخول عبر HOP ID يمنحك معارض خاصة ومفاتيح API دائمة.

هل يمكنني استضافة PixelHop على خادمي الخاص؟

نعم. يترجم PixelHop إلى ملف تنفيذي مستقل بلغة Go دون أي متطلبات تشغيل خارجية. راجع دليل README في المستودع.

أين أبلغ عن المشكلات أو الثغرات الأمنية؟

يمكنك فتح مشكلة في GitHub أو مراسلتنا عبر security@hel.ink للإبلاغ المسؤول عن الثغرات.

عائلة HOP

PixelHop جزء من HOP، حزمة أدوات خفيفة ومستقلة وقابلة للاستضافة الذاتية بحساب موحد.
