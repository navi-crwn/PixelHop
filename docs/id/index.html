Fitur

Semua yang harus dilakukan image host. Tanpa yang tidak perlu.

Tidak ada paket premium yang menyembunyikan fitur bagus. Semua akun dapat semua fitur.

Lokasi dihapus, kualitas tetap

Foto dari HP membawa koordinat GPS dan nomor seri kamera. PixelHop menghapus EXIF, XMP dan IPTC dengan menulis ulang wadah file, jadi piksel tidak dikompres ulang, dan foto yang miring diluruskan dulu.

Semua jenis link

Link yang mudah dibaca seperti pantai-senja-x7Kp2Q, link langsung, Markdown, HTML, BBCode dan QR code. Pratinjau tampil rapi di Discord, X, WhatsApp dan forum.

Album

Lempar beberapa foto, bagikan sebagai satu link galeri.

Hapus otomatis

Hapus setelah 10 menit, sehari atau sebulan. Tamu dapat link hapus pribadi.

ShareX & API

Config ShareX sekali klik, REST API dengan key. Config PixelHop 2 tetap jalan.

Host sendiri

Satu binary, image Docker atau systemd. Disk, R2, MinIO, B2, Contabo.

Moderasi bawaan

Laporan, sembunyikan/hapus, ban IP, kunci atau suspend akun, peringatan.

Copy semua link sekaligus

Setelah upload massal: semua link direct, halaman, Markdown, BBCode atau HTML dengan satu klik. Galeri juga bisa diunduh sebagai ZIP.

Privat atau pakai password

Per gambar: siapa saja yang punya link, hanya kamu, atau pakai password. File yang dikunci tidak bisa di-hotlink.

Resize lewat URL, statistik

?w=800&format=webp membuat ukuran apa pun. Pemilik melihat jumlah view per hari dan situs mana yang menautkan.

Bisa di-install, HEIC, watermark

Pasang di layar utama dan bagikan foto langsung ke sana. HEIC iPhone otomatis dikonversi. Beri watermark satu gambar atau sekaligus banyak.

Webhook, oEmbed, CLI

Webhook bertanda tangan, embed untuk WordPress dan Notion, feed Explore, dan pixelhop push dari terminal.

Satu akun dengan HEL.ink

Di p.hel.ink kamu login dengan akun HEL.ink: login yang sama untuk short link, halaman bio dan gambar, lengkap dengan Google dan kode 2FA. Yang self-host bisa mematikannya.

Link lama tetap jalan

Semua link halaman, direct dan thumbnail dari PixelHop 2, beserta config ShareX dan halaman hasil upload, tetap berfungsi seperti dulu.

Studio

Studio foto yang tidak pernah mengunggah fotomu.

Sebagian besar alat jalan di perangkatmu sendiri dengan Canvas dan WebAssembly, jadi gambar baru keluar kalau kamu menekan “Upload result”. Alat AI yang berat jalan di server, untuk member, dan tidak menyimpan apa pun.

  • Kompres, ubah ukuran, crop, konversi ke JPG, PNG, WebP atau AVIF, ukuran file langsung terlihat.
  • Atur & putar: terang, kontras, warna, hitam putih, balik.
  • Blur & pikselkan wajah, plat nomor dan nama sebelum dibagikan.
  • Gambar jadi teks (OCR) dalam 30 bahasa, beberapa sekaligus dalam satu gambar.
  • Hapus background dengan model AI yang jalan di browser.
  • Palet warna dan pembuat QR code (PNG atau SVG).
  • Di server, untuk member: hapus background dalam sedetik, blur wajah otomatis, magic eraser dan HD upscale 2×. Diproses di memori, tidak disimpan.
  • Batch: jalankan langkah yang sama ke banyak gambar, lalu dapat satu ZIP atau satu album.

Self-host

Jalan dalam satu menit.

Tanpa PHP, Python, MySQL atau cron. Akun pertama yang dibuat otomatis jadi admin.

# Linux (amd64). Versi arm64, macOS dan Windows ada di halaman Releases.
curl -L -o pixelhop https://github.com/navi-crwn/pixelhop/releases/latest/download/pixelhop-linux-amd64
chmod +x pixelhop
PIXELHOP_BASE_URL=https://img.example.com ./pixelhop
docker run -d --name pixelhop -p 8080:8080 \
  -e PIXELHOP_BASE_URL=https://img.example.com \
  -v pixelhop:/data ghcr.io/navi-crwn/pixelhop:latest
# Go 1.27+
git clone https://github.com/navi-crwn/pixelhop.git && cd pixelhop
make build && ./pixelhop

FAQ

Pertanyaan

Gratis?

Ya. p.hel.ink gratis dipakai, dan kodenya berlisensi MIT, jadi kamu bisa menjalankan versimu sendiri, bahkan untuk komersial.

Perlu akun?

Tidak. Tamu bisa mengunggah dan mendapat link hapus pribadi untuk setiap gambar (juga tersimpan di browser). Dengan akun kamu dapat galeri, kuota yang terlihat, dan API key.

Apakah studio privat?

Sebagian besar alat jalan di perangkatmu dan tidak mengirim gambar ke mana pun. Alat AI bertanda “server” (hapus background cepat, blur wajah, magic eraser, HD upscale) mengirimnya ke server, memprosesnya di memori lalu membuangnya; kamu yang memilih kapan memakainya.

Storage apa saja yang bisa dipakai?

Disk lokal, atau bucket S3 apa saja: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi, Contabo. Isi S3_PUBLIC_URL untuk menyajikan gambar langsung dari CDN.

Bagaimana melaporkan gambar?

Setiap halaman gambar punya tombol Report. Laporan langsung masuk antrean moderator, yang bisa menyembunyikan atau menghapus gambar dan memblokir pengunggahnya.

Kenapa Go?

Image host sebagian besar waktunya memindahkan byte. Go melakukannya dengan memori kecil, dikompilasi jadi satu file berisi semuanya, dan bisa dibuat untuk server apa pun. PixelHop 2 butuh PHP, MySQL, Python dan cron; PixelHop 3 tidak butuh apa-apa selain dirinya sendiri.
