HOP · Hosting gambar & studio foto

Letakkan gambar, bersihkan metadata, bagikan dalam hitungan detik

PixelHop menghadirkan pengunggahan gambar kilat, galeri album, dan studio foto privat langsung di peramban. Tautan pendek bersih di p.hel.ink dan dashboard Anda di pixel.hel.ink. Satu biner Go, mandiri, open source (MIT).

Kemampuan PixelHop

  • Unggah kilat & tautan bersih

    Tarik foto, tangkapan layar, atau karya seni untuk tautan pendek rapi di p.hel.ink/{slug}, tautan langsung, Markdown, dan kode semat.

  • Pembersihan metadata bawaan

    Koordinat GPS, nomor seri perangkat, dan tag EXIF dibuang dengan menyusun ulang wadah file tanpa mengompresi ulang piksel asli.

  • Studio foto privat di peramban

    Kompres, ubah ukuran, pangkas, konversi ke WebP/AVIF, samarkan bagian sensitif, dan jalankan OCR langsung di peramban tanpa mengunggah.

  • Satu login untuk semua app: HOP ID

    Masuk mulus dengan akun single sign-on HOP ID di seluruh keluarga aplikasi HOP, atau gunakan PixelHop sebagai tamu.

  • Album & berbagi banyak file

    Unggah banyak gambar sekaligus menjadi galeri responsif, salin semua tautan sekali klik, atau unduh arsip ZIP gabungan.

  • Tautan berbatas waktu & terlindungi

    Atur timer hapus otomatis (10 menit, 24 jam, 30 hari) atau lindungi dengan kata sandi. Tamu mendapatkan token penghapusan privat.

  • ShareX & REST API

    Konfigurasi ShareX siap pakai, pengunggahan CLI melalui pixelhop push, dan token API personal untuk otomatisasi.

  • Biner tunggal Go mandiri

    Berjalan sebagai satu file eksekusi Go ringan (~16 MB) dengan SQLite bawaan, mendukung penyimpanan disk lokal atau object storage kompatibel S3.

Tanya Jawab

Apakah PixelHop menurunkan mutu gambar saya?

Tidak. Pembersihan metadata menghapus header EXIF dan GPS dengan menulis ulang wadah file tanpa mengenkode ulang piksel gambar aslinya.

Apakah saya wajib mendaftar akun?

Tidak. Pengunggahan tamu didukung penuh disertai token hapus privat. Masuk dengan HOP ID membuka galeri akun dan kunci API persisten.

Bisakah saya meng-host PixelHop sendiri?

Bisa. PixelHop dikompilasi menjadi satu biner mandiri Go tanpa ketergantungan runtime eksternal. Lihat petunjuk di README repo.

Di mana saya dapat melaporkan masalah atau bug?

Buka issue di GitHub atau kirim surel ke security@hel.ink untuk pelaporan kerentanan secara bertanggung jawab.
