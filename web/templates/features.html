Features

Everything is free for everyone. No premium tier.

Sharing

  • Images, videos and PDFs up to {{.MaxMB}} MB each, {{.MaxBatch}} at a time, by drag and drop, paste, or a link.

Privacy

  • Location removed: GPS and camera details are stripped from every upload.

Studio

Compress, resize, crop, convert, adjust, blur faces and plates, read text, remove backgrounds and pull a color palette. Most tools run on your device. Open the studio.

For developers

A REST API with keys and a ready-made ShareX config. Read the API docs.

Accounts

Sign in with your HOP ID for a gallery, albums, a public profile and higher limits.
