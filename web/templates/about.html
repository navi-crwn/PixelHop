About {{.Site}}

{{.Site}} is free, open-source hosting for images, videos and PDFs. Drop a file, get a link that previews well everywhere, and keep your location to yourself: GPS and camera data are removed before anyone sees the file.

Who runs it

{{.Site}} is part of HOP, a small family of free apps run by one person on one server, with no ads and no trackers. The code is MIT licensed and public on GitHub; you can run your own copy.

How it is built

One Go program and one SQLite file. Thumbnails and the metadata cleanup happen on upload; most studio tools run in your browser, so the image never leaves your device.
